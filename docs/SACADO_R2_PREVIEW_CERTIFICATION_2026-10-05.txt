- sacados represents the company/full CNPJ. Nullable legacy user_id preserved.
- sacado_acessos represents user + company + fund, with status and audit.
- Exact normalized full CNPJ + active fund membership; never CNPJ root.
- Set-based context drives dashboard, indicators, lists, RLS and storage.
- Batch validation completes before mutation; all invoices must be accepted
  before the operation is marked accepted.
- Administrative management at /gestor/configuracoes/sacados and
  /admin/usuarios/sacados: paginated search, detail, company lookup/create,
  grant/revoke/activate/deactivate/update, explicit confirmation and fresh MFA.
- Sensitive authorization nonce consumed within the mutation transaction.
- Notification recipients for acceptance/contest and maturity lookup use
  active memberships; no reliance on the old company-owner user_id.
- Optional Table container attributes enable keyboard scrolling on the
  Sacado NF list without changing other table instances.
